# Mercado Inteligente — Frontend

Frontend do **Mercado Inteligente**, projeto acadêmico desenvolvido como parte do curso de Análise e Desenvolvimento de Sistemas da Fatec Guarulhos.

A proposta do projeto é contribuir para o gerenciamento de estoques e o controle do giro de alimentos, utilizando tecnologia para auxiliar a organização e a gestão de estabelecimentos comerciais.

## Tecnologias

- **HTML5** — estruturação das páginas.
- **CSS3** — estilização e apresentação visual.
- **JavaScript** — implementação de interatividade e lógica no frontend.

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/Fatecos-GR/Mercado-inteligente_Frontend.git
   ```
2. Acesse a pasta do projeto.
3. Abra o arquivo `index.html` em seu navegador.

Não é necessário instalar dependências para executar a interface básica.
